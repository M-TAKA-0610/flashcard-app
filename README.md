# IT用語 単語帳

情報系の学生が情報技術の基本用語を学習するための単語帳Webアプリです。
HTML / CSS / JavaScript のみで作成しており、サーバーやデータベースは不要です。

## 使い方

`index.html` をブラウザで開くだけで動作します（PC・スマートフォン対応）。

- カードをクリック（タップ）すると、表面（用語）と裏面（説明）が切り替わります
- 「前へ」「次へ」ボタンで前後のカードに移動できます
- 「シャッフル」でカードの順番をランダムに並べ替えます
- PC: `←` `→` キーで移動、`Space` / `Enter` で裏返し
- スマートフォン: カードを左右にスワイプして移動

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | デザイン（レスポンシブ・ダークモード対応） |
| `script.js` | 用語データ（20語）と操作処理 |

用語を追加・変更する場合は、`script.js` の `WORDS` 配列を編集してください。
