# IT用語 単語帳

情報系の学生が情報技術の基本用語を学習するための単語帳Webアプリです。
HTML / CSS / JavaScript のみで作成しており、サーバーやデータベースは不要です。

**公開URL：** https://m-taka-0610.github.io/flashcard-app/

## 主な機能

- **単語カード**：表面に用語、裏面に説明。クリック（タップ）で3D回転して裏返ります
- **110語を収録**：ハードウェア、OS・ソフトウェア、プログラミング、アルゴリズム、ネットワーク、Web、セキュリティ、データベース、AI、クラウド・インフラ、開発の11カテゴリ
- **カテゴリ別学習**：画面上部のカテゴリを選ぶと、そのカテゴリの単語だけを学習できます
- **覚えた／まだの記録**：カードごとに記録でき、カテゴリごとの習得数を表示します。「未習得のみ」をオンにすると、まだ覚えていない単語だけを出題します
- **学習状況の保存**：記録や表示中のカードはブラウザ（localStorage）に保存され、閉じても続きから再開できます
- **単語の追加・編集・削除**：「単語管理」から自分で単語を登録・変更できます。検索もできます
- **シャッフル**：カードの順番をランダムに並べ替えます
- PC・スマートフォン対応（スワイプで移動、キーボード操作にも対応）

## 操作方法

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| 裏返す | カードをクリック / `Space` | カードをタップ |
| 前後に移動 | `←` `→` / ボタン | 左右にスワイプ / ボタン |
| 覚えた | `↑` / 「覚えた」ボタン | 「覚えた」ボタン |
| まだ | `↓` / 「まだ」ボタン | 「まだ」ボタン |

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | デザイン（レスポンシブ対応のダークテーマ） |
| `script.js` | 学習・記録・保存・単語管理の処理 |
| `words.js` | 初期の単語データ（110語） |

## データの保存について

学習記録や追加した単語は、利用しているブラウザの中（localStorage）にだけ保存されます。
別の端末やブラウザとは共有されません。ブラウザの閲覧データを削除すると記録も消えます。
